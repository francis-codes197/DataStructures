Data Structures Practical Assignments

Project Description

This repository contains practical programming assignments for the Data Structures course. The programs are written in the C programming language and demonstrate different data structures and algorithms.

Programming Language

- C
- Compiler: Clang

Practical Questions

File| Description
"question1.c"| Circular queue implementation
"question4a.c"| Recursive sum
"question4b.c"| Factorial using recursion
"question4c.c"| Nth Fibonacci number
"question4d.c"| Generating Fibonacci terms
"question5.c"| Queue operations
"question6.c"| Sparse matrix
"question7.c"| Double-ended queue (Deque)

How to Compile and Run

To compile a program using Clang:

clang question1.c -o question1

To run it:

./question1

Replace "question1" with the name of the program you want to compile and run.

For example, to compile and run Question 7:

clang question7.c -o question7
./question7

Development Environment

The programs were written, compiled and tested using Termux on an Android device.
